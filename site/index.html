Overview

MemUse evaluates agent memory at its point of use. It checks which delivered memories shaped an agent’s actions and what followed from their use.

Look beyond task success

A successful task can include a harmful memory detour. A failed task can include useful guidance. MemUse follows each delivery through the recorded actions and consequences, so you can inspect both cases. See the paper’s results.

Record, then evaluate

The three projects form one workflow. To analyze existing annotated recordings, install only MemUse. Its tools read the recording without changing the memory store or rerunning the task.

memory-bridge

Connects an agent harness to a memory system. Marks memory searches, writes, deliveries, and task boundaries.
