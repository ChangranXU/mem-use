2. accuracy (@accuracy@) — is the memory's claim correct within its own
   scope (the repository, version, bug, or situation it describes), judged
   from evidence observable in the step stream (tool results, file contents,
   test outcomes)? corroborated = observable evidence confirms the claim in
   that scope; contradicted = observable evidence refutes the claim in that
   scope; uncontradicted = neither (nothing observed addresses it). Current
   code that differs from a claim about another bug, release, or repository
   does not by itself refute that historical claim. Assess applicability to
   the current problem separately under relevance. Do not guess beyond what
   is observable.
