5. positive_effect (@positive_effect@) — only when
   influence is acted_on or decisive: did the memory move the agent TOWARD
   what the GOLDEN ANSWER shows the task required (improved), or steer it
   AWAY from it (harmed)? Judge the direction against the gold text. The
   gold is a reference solution, not the only valid one: environment
   repair, verification, and avoiding a demonstrated dead end can improve
   the work without appearing in the gold patch, and matching the patch is
   not by itself proof the memory caused the action. Judge by the
   observable consequences of actions anchored inside the memory's footprint
   window, including later results tied to those actions; never infer what
   would otherwise have happened. Saved effort needs the
   observable anchor from influence (announced intent or explicit credit,
   cited in the note) plus the step's absence afterward.
   improved = a downstream event ties the benefit to the memory-shaped
   action: a choice or edit the following steps build on, a test that
   failed before and passes after it, an error avoided where the agent was
   observably headed into it.
   no_effect = the memory-shaped action produced no observable downstream
   change: the command's output was not used afterward, the edit was
   reverted or superseded, the test result was unchanged.
   harmed = it led the agent astray of what the gold required (wrong
   location, false lead, reverted correct work).
   Affirmative evidence is required for every effect value: the absence of
   a failure the memory warned about is NOT evidence of benefit unless the
   memory's guidance was observably applied where the agent would otherwise
   plausibly have failed; a counterfactual you cannot check ("without the
   memory the agent would have done X") is speculation, not evidence.
   Accuracy never decides this signal: a memory carrying a false claim can
   still have set off the diagnostic that found the fix — judge the effect
   by the downstream events, whatever the accuracy call. When
   influence is acted_on but the direction cannot be determined on the
   evidence available, say null — an unresolved causal question is
   uncertainty, never a confident no_effect, and never silently improved
   either.
   null when influence is none or referenced.
