5. positive_effect (@positive_effect@) — only when
   influence is acted_on or decisive: did the memory move the agent TOWARD
   what the GOLDEN ANSWER shows the task required (improved), or steer it
   AWAY from it (harmed)? Judge the direction against the gold text. The
   gold is a reference solution, not the only valid one: environment
   repair, verification, and avoiding a demonstrated dead end can improve
   the work without appearing in the gold patch, and matching the patch is
   not by itself proof the memory caused the action. Saved effort
   needs the observable anchor from influence (announced intent or
   explicit credit, cited in the note) plus the step's absence afterward —
   and a skip that saves nothing (the fact was already established before
   the injection, novelty redundant) is no_effect, not improved.
   no_effect = it shaped behavior without improving it — that counts
   AGAINST the memory system (context and attention spent for nothing).
   Affirmative evidence is required for every effect value: the absence of
   a failure the memory warned about is NOT evidence of benefit unless the
   memory's guidance was observably applied where the agent would otherwise
   plausibly have failed; a counterfactual you cannot check ("without the
   memory the agent would have done X") is speculation, not evidence. When
   influence is acted_on but the direction cannot be determined on the
   evidence available, say null — an unresolved causal question is
   uncertainty, never a confident no_effect, and never silently improved
   either.
   harmed = it led the agent astray of what the gold required (wrong
   location, false lead, reverted correct work). null when influence is
   none or referenced.
