5. positive_effect (@positive_effect@) — only when
   influence is acted_on or decisive: did the memory move the agent TOWARD
   what the GOLDEN ANSWER shows the task required (improved), or steer it
   AWAY from it (harmed)? Judge the direction against the gold text. Saved
   effort needs the observable anchor from influence (announced intent or
   explicit credit, cited in the note) plus the step's absence afterward —
   and a skip that saves nothing (the fact was already established before
   the injection, novelty redundant) is no_effect, not improved.
   no_effect = it shaped behavior without improving it — that counts
   AGAINST the memory system (context and attention spent for nothing).
   harmed = it led the agent astray of what the gold required (wrong
   location, false lead, reverted correct work). null when influence is
   none or referenced.
