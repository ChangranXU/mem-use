4. influence (@influence@) — what this entry demonstrably shaped inside its
   stated footprint window:
   - none: after inspecting the whole window, no reference or attributable
     action was established. This is not proof of zero effect;
   - referenced: mentioned or quoted, but no changed action established.
     The mention must single out this entry (its shown identifier,
     distinctive content, or list position); a remark about the results as
     a whole, such as "nothing matched", references no entry unless this
     entry was the only one shown;
   - selected: its shown identifier or preview caused retrieval of fuller
     memory content that the record shows as its own memory delivery (the
     step's result reads [memory delivery …]; span.md lists proven
     follow-ups), with no other demonstrated use of this entry's content.
     Anchor the selection action, not the result-delivery step. Check the
     whole window for other uses of this entry. Selection proves retrieval,
     not benefit: positive_effect is null, and the returned
     content's effect is judged on that delivery. A retrieval whose result is
     not a recorded delivery, or opening repository code or task data at a
     distinctive path supplied by memory, is acted_on, not selected: nothing
     else judges what it returned, so its consequence is this entry's effect;
   - acted_on: an action uses distinctive exposed content, explicitly credits
     the memory, or demonstrably changes a prior direction because of it.
     Anchor the action or a decision later substantiated by execution. An
     unexecuted plan, a matching phrase, or routine practice alone is not use;
   - null: an action in the window uses this entry's distinctive exposed
     content, but an independent source supports that same action equally
     and the record cannot decide; or the window was not inspected
     sufficiently. Independent sources are the task, code and tool output,
     and reasoning stated before the delivery; a plan first stated after the
     delivery is not one. Name the action and the competing source, or the
     unread evidence; positive_effect is null. When no action uses the entry's
     distinctive content (its specific mechanism, location, or remedy) and
     other sources explain the actions, use none: a shared general
     direction is not ambiguity.

   Start with the first consuming step: it is already post-exposure. A prior
   direction needs an earlier step or pre-exposure input, not a plan first
   stated after delivery. Continuing that direction does not establish use;
   a reminder that restores a dropped plan or supplies missing detail can.
   A skipped action needs a pre-delivery announced intent or explicit credit.
   Distinguish task requirements, prior code/tool evidence, common practice,
   and memory. Expected task outputs do not automatically supply the solution.
   A generic practice matching later behavior (such as a small diff, or
   targeted tests before the full suite) is not distinctive content: without
   explicit credit or a demonstrated change of direction, influence is none.

   Other deliveries are competing sources, with one exception: when a
   preview's shown identifier selected a recorded fuller delivery of the same
   memory, content both carry is the fuller delivery's to credit. The preview
   stays selected unless it shaped an action before that delivery arrived or
   with content the fuller delivery lacks (then acted_on, citing that
   action, without borrowing the full read's benefit); the fuller delivery's
   judge never treats its selecting preview as a competing source for that
   shared content. This is a credit-allocation convention, not evidence of
   causation: first establish an action attributable to the memory chain,
   compared with the task, code, and prior reasoning. It does not transfer an
   action already shaped before the fuller delivery arrived, nor make a
   later repetition influential when the agent is continuing an already
   executed or substantiated plan. Credit only what this entry exposed,
   including shown selectors, never hidden keys or canonical suffixes. A
   preview can directly shape an edit without being opened. A changed or
   narrower later exposure may share the window.

   Notes name the consuming step, action, and source. Anchors stay in the
   entry's window; later episode results can establish an anchored action's
   consequence without becoming action anchors themselves.
